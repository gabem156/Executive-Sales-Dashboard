# Executive Sales Dashboard

## Project Overview

This project presents an interactive Executive Sales Dashboard built in Tableau to analyze sales performance, profitability, and customer segments using the Superstore dataset.

The dashboard enables users to monitor key business metrics, identify top-performing regions and product categories, and explore sales trends through interactive filters.

---

## Business Problem

Business leaders need a centralized view of sales performance to make informed decisions, identify growth opportunities, and monitor profitability across different regions and product categories.

This dashboard provides an executive-level overview of key performance indicators (KPIs) and sales insights.

---

## Tools Used

* Tableau Public
* Microsoft Excel / CSV Data Source

---

## Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Quantity Sold

---

## Dashboard Features

### Sales by Region

Analyzes sales performance across geographic regions.

### Profit by Category

Identifies the most profitable product categories.

### Sales by Segment

Compares sales performance across customer segments.

### Interactive Filters

Users can filter dashboard results by:

* Region
* Category

---

## Key Insights

* The West region generated the highest sales performance.
* Technology was the most profitable product category.
* Consumer customers contributed the highest sales volume.
* Sales and profit performance can be explored interactively through dashboard filters.
